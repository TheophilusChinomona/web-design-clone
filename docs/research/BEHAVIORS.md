# Behaviors & Interaction Specification — EdgeTech Solutions

## 1. Global Navigation & Mobile Menu
- **Desktop Navbar:**
  - Sticky/top header with brand logo on left, 5 navigation links (`Home`, `About`, `Services`, `Our Process`, `Contact`), and `"Let's Talk"` action button.
  - Active link highlight and hover underline/color change to `#6592c7`.
- **Mobile Menu:**
  - Hamburger trigger button (accessible SVG icon).
  - Off-canvas / animated sliding mobile drawer displaying all page links and CTA.

## 2. Interactive Project Carousel (Home Page)
- **Component:** Image Carousel with autoplay (5000ms delay), swipe/drag navigation, next/prev arrow buttons, and pagination indicator dots.
- **Images:** `home-projects-03.webp`, `home-projects-01.webp`, `home-projects-02.webp`.

## 3. Numbered Feature Service Cards
- 3 distinct feature cards on Home & Services:
  - 01. Precision Wood Edging
  - 02. Surface Finishing
  - 03. Custom Edge Solutions
- Subtle card hover elevation, clean border styling, and responsive 1-column (mobile) to 3-column (desktop) grid.

## 4. Multi-Step Industrial Process Showcase (Our Process Page)
- Sequential 3-step breakdown with numbered badges (`01.`, `02.`, `03.`), technical review details, and dual-image showcases for each production phase.

## 5. Contact Form & Interactive Map (Contact Page)
- Complete client-side validated form:
  - Full Name
  - Email Address
  - Subject
  - Message textarea
  - Interactive submit button with sending/success state.
- Interactive embedded Google Maps iframe for Unit G21, Cnr. Brand Rd & Swart Dr, President Park A/H, Midrand.

## 6. Social Media Links & Hover Micro-Interactions
- Custom branded hover colors on Facebook (`#557dbc`), Twitter (`#7acdee`), YouTube (`#e96651`), Instagram (`#8a3ab9`), and LinkedIn (`#1c86c6`) with smooth scale-up transitions.
